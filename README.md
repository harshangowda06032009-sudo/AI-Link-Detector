# 🛡️ AI Link Detector - Phishing & Fraud Link Blocker App

An intelligent Android application that scans clicked links in real time and blocks phishing scams, fake bank KYC links, and malicious websites.

## 📥 How to Download & Install
1. Click on *Releases* on the right side of this page.
2. Download the *app-debug.apk* file.
3. Install it on your Android phone and set *AI Link Detector* as your *Default Browser App*.
